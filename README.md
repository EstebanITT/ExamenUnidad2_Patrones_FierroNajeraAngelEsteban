# Juego de defensas de torres
**Descripcion**:
Tiene dos botones, saltar turbo y reiniciar, también dos áreas donde cada jugador coloca 5 torres, una vez que jugador 1 coloque da en saltar turno y hace lo mismo el jugador 2 y le dará en saltar turno, comenzará a disparar los proyectiles hasta que sean destruidas
